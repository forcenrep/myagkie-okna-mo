# Фотографии окантовки

Добавьте семь фотографий с именами ниже (jpg, jpeg, png или webp).
После следующей сборки они подключатся к соответствующим цветам автоматически.

- white.jpg — белый
- beige.jpg — бежевый
- brown-gloss.jpg — коричневый глянец
- brown-matte.jpg — коричневый матовый
- light-grey.jpg — светло-серый
- grey.jpg — серый
- dark-grey.jpg — тёмно-серый

Желательно одинаковое соотношение сторон 4:3. Фото показываются целиком.
Исходники автоматически оптимизируются при сборке.
